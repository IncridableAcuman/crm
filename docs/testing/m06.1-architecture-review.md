## 3. Identified Doc-vs-Code Discrepancies & Resolutions

| # | Discrepancy Found During Audit | Ground Truth in Codebase (`M01`–`M05.6`) | M06 Architectural Resolution |
|---|---|---|---|
| 1 | `domain-modules.md` §3.1 placed `Warehouse` under `Tenancy` (`modules/tenancy`) | `modules/tenancy` implements only `Tenant` (`v1.0.0/01`) and `Branch` (`v1.0.0/02`); `Warehouse` does not exist yet | **ADR-0011**: `Warehouse` lives in `com.savdocrm.modules.inventory` with optional `branch_id` FK (`branches(tenant_id, id)`); `domain-modules.md` updated accordingly |
| 2 | `api-conventions.md` & `database-design.md` specify `idempotency_records` table | No `idempotency_records` table or `IdempotencyService` exists in `v1.0.0/00`–`22` or `shared/` yet | **ADR-0016**: Shared `idempotency_records` table & `IdempotencyService` scheduled for `M06.2–M06.3`; full SHA-256 contract specified in `06-inventory-api-contracts.md` |
| 3 | `api-conventions.md` shows `pagination` envelope, `error.details`, and `204` deletes | Implemented `GlobalExceptionHandler` & M04/M05 controllers use `ApiResponse<PageResponse<T>>` (`data.items`), RFC 7807 `ProblemDetail` (`errors` map), and `200 OK` (`ApiResponse<Void>`) | M06 REST contracts strictly match implemented M04/M05 `ApiResponse`, `PageResponse`, and RFC 7807 `ProblemDetail` |
| 4 | Legacy `database-design.md` sketched flat `inventory_stocks` + flat `inventory_transactions` without locations, transit, holds, or WAC table | Inadequate for bin/damage segregation, two-step transit, reservations, and multi-line ledger documents | **ADR-0012 / ADR-0013 / ADR-0014 / ADR-0015**: Dual projections (`inventory_balances` + `inventory_warehouse_stocks`), header-line immutable ledger, separate reservation/document tables, `inventory_costs` (`WAC`) |
| 5 | Legacy `database-design.md` used `ON DELETE CASCADE` on tenant/catalog FKs | M04 (`15`) & M05 (`22`) hardened every foreign key to `ON DELETE RESTRICT` | Every Inventory composite FK enforces strict `ON DELETE RESTRICT` |
| 6 | Legacy docs (`ADR-0007` vs `security.md`) differed on `WAREHOUSE` RBAC scope existence & `WAREHOUSE_MANAGER` default | `RoleScopeType` currently has `{TENANT, BRANCH}`; `WAREHOUSE_MANAGER` temporarily uses `BRANCH` in `SystemRoles.java`; `Permissions.java` has 33 permissions (3 inventory) | **ADR-0016**: Introduce `RoleScopeType.WAREHOUSE` + `user_role_assignments.warehouse_id`, enforce **no implicit `BRANCH -> WAREHOUSE` inheritance**, add 20 new `inventory.*` permissions while keeping existing 3 intact and never touching custom roles |
| 7 | `backend-architecture.md` & `ADR-011` cite Spring Boot `3.4.x` / Gradle `8.10.2` | Codebase runs Java `21`, Spring Boot `4.2.0`, Gradle `9.9.1` | Noted accurately in review & ADRs (older global docs outside M06 scope left untouched except Inventory alignment) |

## 5. Completeness & Architecture-Only Compliance Check

- [x] **Warehouse & Location Design**: Supports multi-warehouse per branch, nullable `branchId` (`CENTRAL_HUB`), default `STORAGE` auto-location, non-sellable pools (`RECEIVING_DOCK`, `DAMAGED`, `QUARANTINE`), stock-guarded deactivation, `RESTRICT` deletion policy.
- [x] **Immutable Ledger & Dual Projections**: Header-line `inventory_transactions`/`inventory_transaction_lines`, compensating `REVERSAL`, strict `StockBalance` + `WarehouseStockSummary` parity, `allow_negative_stock = false` default.
- [x] **Operational Lifecycles**: `StockReceipt`, snapshot-based non-freezing `StockCount`, `StockAdjustment` maker-checker workflow, two-step `StockTransfer` (`in_transit` + good/damaged/shortage receipt variance), `InventoryReservation` (no ledger churn + TTL job).
- [x] **Valuation (`WAC`)**: Explicit per-warehouse-variant `NUMERIC(15,4)` formulas with zero-depletion residue reset and complete decoupling from `Finance` GL.
- [x] **Concurrency & Deadlock Prevention**: Explicit canonical lock ordering `(Operational Doc -> inventory_balances(warehouseId, locationId, variantId) -> inventory_warehouse_stocks(warehouseId, variantId) -> inventory_costs(warehouseId, variantId))` + `INSERT ... ON CONFLICT DO NOTHING` + `Idempotency-Key`.
- [x] **Zero Implementation Code Touched**: Verified via Git working tree check — strictly markdown documentation additions/edits only. Implementation of **M06.2** awaits explicit approval.
